# ⚡ Simulador de Circuitos Mecatrónicos

Simulador interactivo web para estudiantes de mecatrónica de 1er año. Permite cablear componentes físicos (ESP32, Puente H L298N, Regulador LM2596, Motores DC, Servomotor SG90, Baterías de Litio e Interruptor), evaluar la topología eléctrica en tiempo real y generar un **Plano de Conexiones Oficial**.

## 🛠️ Características Principales
- **Zero-Server PWA:** Funciona 24/7 en GitHub Pages desde celulares y computadores.
- **Fotografías Fotorrealistas:** Vista superior plana de módulos físicos reales.
- **Cableado SVG Wokwi-Style:** Cables parabólicos dinámicos con selector de colores y borrado con un clic o tecla `Delete`.
- **Evaluación Topológica:** Verificación de común GND, cadena de potencia 12V, 5V regulados, motores y control PWM.
- **Plano Descargable:** Generación de comprobante sintético con **Alumno**, **RUT**, **MAC PC (Huella Hardware)** y **Código QR**.
